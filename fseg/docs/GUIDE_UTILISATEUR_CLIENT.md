# Guide Utilisateur Du Site Public

Dernière actualisation documentaire : 25 septembre 2026.

Ce guide s'adresse aux visiteurs du site.

## Accueil

La page d'accueil présente la faculté, le carrousel d'images, les
statistiques, les formations mises en avant, la recherche et les
actualités/événements récents. Une ancienne section « atouts » peut encore
apparaître si des données legacy existent en base ; elle n’est plus gérée
depuis l’administration.

## Langue

Le site s'ouvre en français par défaut. Le visiteur peut choisir français ou anglais avec le sélecteur de langue. Si une traduction anglaise n'existe pas encore pour un contenu, le texte français reste affiché.

## Faculté

La page Faculté présente l'institution, ses informations clés et son historique.

## Formations

La page Formations liste les programmes par niveau : licence, master et doctorat. Chaque formation publiée peut avoir une page détail avec résumé, durée, conditions d'admission, description et débouchés.

## Recherche

La page Recherche présente les laboratoires, publications, projets et statistiques de recherche publiés.

## Corps Enseignant

La page Personnel présente les enseignants-chercheurs et personnels administratifs publiés. Un membre peut disposer d'une page détail.

## Actualités Et Événements

La page Actualités affiche les contenus publiés. Le visiteur peut filtrer par type et rechercher par texte. Les événements peuvent indiquer une date, un lieu et un lien d'inscription.

## Alumni

La page Alumni présente des profils d'anciens étudiants, des statistiques et des témoignages.

## Contact

La page Contact permet d'envoyer un message à la faculté. Le formulaire demande le nom, l'adresse email, le sujet et le message; le téléphone est facultatif.

Après validation, le message est enregistré et peut déclencher une notification email si l'administrateur technique l'a activée.

## Confidentialité Des Informations Saisies

Les informations envoyées par le formulaire de contact sont destinées à l'administration de la faculté. Elles sont consultables dans le back-office par les personnes autorisées.
